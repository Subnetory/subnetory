Adresses IP

Créer, rechercher, réserver en masse et modifier des adresses IP.

Créer une adresse

Menu Adresses IP → Nouvelle adresse. Une adresse appartient toujours à un sous-réseau ; les champs nom d'hôte, adresse MAC et description sont optionnels.

Permissions requises : ROLE_ADMIN ou ROLE_IP.

Assistant IP disponible

Une fois un sous-réseau sélectionné dans le formulaire, le bouton Suggérer une IP disponible s'active. Cliquer sur une IP proposée remplit automatiquement le champ adresse — évite de calculer manuellement quelles adresses du bloc sont déjà prises.

Réservation multiple

Menu Adresses IP → ⊞ Réserver plusieurs IP (ou bouton Réserver IP d'un sous-réseau, qui présélectionne ce sous-réseau). La page propose quatre modes, du plus simple au plus structuré : une liste d'IP libres, une série à noms incrémentés, plusieurs séries enchaînées et un template de cluster ou d'infrastructure. Tous aboutissent au même tableau éditable avant toute écriture en base.

Le tableau présente une ligne par adresse (IP, statut, nom d'hôte, description, MAC, temporaire). Vous pouvez corriger l'IP et le nom de chaque ligne, décocher les lignes à ignorer, puis cliquer sur Vérifier les adresses pour recalculer les statuts (Libre, Occupée, Passerelle, Hors plage, Doublon, IP invalide). Réserver ces adresses est « tout ou rien » : si une seule adresse est occupée ou invalide, aucune n'est créée. Un rapport (créées, mises à jour, ignorées, erreurs) s'affiche ensuite.

Permissions requises : ROLE_ADMIN ou ROLE_IP.

Mode 1 — liste d'IP libres

Choisissez un sous-réseau et un nombre d'IP (jusqu'à 50), puis Générer les IP disponibles : Subnetory propose les premières adresses libres du bloc. + Générer des lignes supplémentaires en ajoute d'autres, Tout effacer repart de zéro. Complétez noms d'hôte, descriptions et MAC à la main.

Mode 2 — série avec noms incrémentés

Pour des adresses contiguës nommées avec un compteur (ex. NTNX-HOST-01, NTNX-HOST-02…). Renseignez le sous-réseau, l'IP de départ, le nombre d'adresses et le pas entre adresses (1 = contiguës, 2 = une sur deux…), puis le préfixe, le compteur de départ, le nombre de chiffres du compteur (2 donne 01, 02…) et le suffixe du nom. Avec « Sauter les adresses occupées », les IP déjà prises sont ignorées sans casser la numérotation ; sinon, une adresse occupée bloque toute la série. Aperçu de la série affiche le résultat avant réservation.

Mode 3 — plusieurs séries enchaînées

Pour réserver d'un coup plusieurs groupes à la suite, à partir d'une même IP de départ — par exemple, pour 3 nœuds : HOST ×3, puis CVM ×3, puis IPMI ×3. Chaque groupe a un libellé, un nombre d'adresses et sa propre règle de nommage (préfixe, compteur, chiffres, suffixe) ; les groupes sans nombre d'adresses sont ignorés. Adresses libres entre deux groupes laisse un espace entre les blocs.

Mode 4 — template de cluster ou d'infrastructure

Un template décrit à lui seul les groupes (hôtes, CVM, IPMI/BMC…) et leur nommage : il suffit d'indiquer le nombre de nœuds. Templates livrés : Nutanix (Dell, HPE, Lenovo, Supermicro, ou un sous-réseau par rôle), Proxmox VE, VMware ESXi et serveurs (Dell, HPE, Lenovo, Supermicro). Vous pouvez aussi créer les vôtres (voir « Gérer les templates » ci-dessous).

Choisissez le sous-réseau et le template.
Saisissez le nom du cluster (ex. NTNX01), le site si le template l'utilise et le nombre de nœuds.
Indiquez l'IP de départ : les adresses s'enchaînent à partir de là, groupe après groupe. Avec le template « un sous-réseau par rôle », un tableau permet de choisir, pour chaque rôle (IPMI, HOST, CVM), son sous-réseau et son IP de départ facultative ; par défaut, chaque rôle utilise le sous-réseau choisi plus haut.
Au besoin, réglez les adresses libres entre deux groupes et le pas entre adresses (vides : valeur du template), le comportement si une adresse est occupée (bloquer toute la série ou sauter) et une description commune à toutes les lignes.
Cliquez sur Aperçu du template, corrigez les lignes du tableau si nécessaire (IP, nom, description de chaque ligne), puis Réserver ces adresses.

Exemple : template Nutanix - Supermicro, cluster ntx02, 3 nœuds, départ 10.20.20.100 → HOST ntx02-HOST-01 à -03 en .100–.102, CVM en .103–.105, IPMI en .106–.108.

Gérer les templates

Bouton Gérer les templates de la page de réservation (/network/series-templates). La liste distingue les templates livrés (lecture seule : à dupliquer pour les adapter) et les templates de votre contexte, que vous pouvez créer, modifier et supprimer.

Un template définit : son nom et sa description ; le mode d'allocation — groupes à la suite (tous les hôtes, puis toutes les CVM…), entrelacé (hôte, CVM et IPMI du nœud 1, puis du nœud 2…) ou un sous-réseau par rôle (IPMI, hôtes et CVM chacun dans leur sous-réseau) ; l'écart entre groupes ; le pas entre adresses ; et la liste des groupes (rôle, libellé, format du nom, nombre fixe d'adresses facultatif).

Le format du nom contient exactement un compteur — {n}, {nn}, {nnn}… (le nombre de n donne le nombre de chiffres) — et, au choix, les variables {cluster}, {site} et {role}. Exemple : {cluster}-{role}-{nn} donne NTNX01-HOST-01. Sans nombre fixe, un groupe compte autant d'adresses que de nœuds.

Création, modification et suppression : ROLE_ADMIN ou ROLE_IP. Les mêmes droits sont requis pour réserver des adresses.

Rechercher une adresse

Menu Adresses IP. Filtres disponibles : recherche libre, nom d'hôte, adresse MAC. La liste est paginée (25 adresses par page).

Modifier et supprimer

Dans la liste Adresses IP, Modifier ouvre le formulaire de l'adresse et Supprimer la retire après confirmation.

Pour en supprimer plusieurs d'un coup : cochez les lignes (la case de l'en-tête sélectionne toute la page affichée), cliquez sur Supprimer la sélection puis confirmez dans la boîte de dialogue. L'opération est irréversible, limitée à 500 éléments à la fois, et chaque adresse supprimée est tracée individuellement dans le journal d'audit.

Permissions requises : ROLE_ADMIN ou ROLE_IP.

Export

Boutons ↓ CSV et ↓ Excel disponibles sur les pages Adresses IP et Sous-réseaux. Les filtres actifs au moment de l'export sont appliqués au fichier généré.
