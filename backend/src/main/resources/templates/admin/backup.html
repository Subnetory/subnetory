Configuration

Format : secondes minutes heures jour-du-mois mois jour-de-semaine. Le configurateur ci-dessus couvre les cas courants (dont Intervalle pour "toutes les N heures" ou "tous les N jours", ex. un jour sur deux) et repasse automatiquement en Personnalisé pour toute expression qu'il ne reconnaît pas exactement — le champ texte reste alors modifiable directement. Exemples : 0 0 2 * * * tous les jours à 2h — 0 0 */6 * * * toutes les 6 heures — 0 0 2 * * SUN chaque dimanche à 2h.

Au-delà de ce nombre, les fichiers les plus anciens sont supprimés automatiquement après chaque sauvegarde réussie. L'historique, lui, est conservé indéfiniment.
