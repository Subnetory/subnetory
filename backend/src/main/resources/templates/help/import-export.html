Import & export

Reprendre un inventaire existant en CSV ou Excel, et comprendre le format attendu.

Importer des adresses

Menu Adresses IP → Importer des adresses. Formats acceptés : CSV et Excel (.xlsx), avec les mêmes colonnes et les mêmes règles pour les deux formats.

Après import, un rapport s'affiche avec le nombre de lignes traitées, créées, mises à jour et en erreur — avec le détail ligne par ligne pour les erreurs.

Colonnes attendues

ColonneObligatoireDescription
addressOuiAdresse IPv4, ex. 192.168.1.10
subnet_idsubnet_id ou subnet_networkID numérique du sous-réseau
subnet_networksubnet_id ou subnet_networkRéseau CIDR, ex. 192.168.1.0/24
macNonAdresse MAC
hostnameNonNom d'hôte
descriptionNonDescription libre
temporaryNontrue ou false, défaut false
discovery_sourceNonmanual / api / csv / xlsx / nmap / arp-scan / dns

Si subnet_id est fourni, il est utilisé directement et le sous-réseau doit déjà exister. Si seul subnet_network est fourni, Subnetory recherche le sous-réseau correspondant — si plusieurs sous-réseaux partagent le même CIDR, la ligne est rejetée pour ambiguïté. Si les deux sont fournis, subnet_id est prioritaire.

Exemple CSV

fichier .csv address,subnet_id,subnet_network,mac,hostname,description,temporary,discovery_source
192.168.1.10,3,,aa:bb:cc:dd:ee:ff,srv-web-01,Serveur web principal,false,csv
192.168.1.20,3,,,,Imprimante RDC,,
192.168.1.30,,192.168.1.0/24,,pc-compta-01,Poste utilisateur,false,manual

Comportement selon l'existence de l'adresse

ÉtatComportement par défautAvec « remplacer les existantes »
IP absenteCréation complèteCréation complète
IP existanteMise à jour de la dernière observation uniquementMise à jour des champs fournis

L'option Remplacer les adresses existantes du formulaire d'import détermine ce comportement : décochée, une IP déjà connue n'est jamais écrasée — seul un conflit est signalé sans modification.

Export

Boutons ↓ CSV et ↓ Excel sur les pages Adresses IP et Sous-réseaux, avec les filtres actifs appliqués au fichier généré.
