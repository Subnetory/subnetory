Configuration

Choisir le champ LDAP comparé à l’identifiant saisi lors de la connexion. Exemple : avec sAMAccountName, le login jdupont recherche le compte dont sAMAccountName vaut jdupont.

Rôles par défaut

Rôles attribués automatiquement lors de la première connexion d’un utilisateur LDAP. READ_ONLY limite l’utilisateur à la consultation des contextes autorisés. IP gère les adresses IP, imports et exports. NETWORK gère les contextes, sites, VLAN, sous-réseaux et scans. ADMIN donne accès à toute l’administration.
