Adresses IP

Créer, rechercher, réserver en masse et modifier des adresses IP.

Créer une adresse

Menu Adresses IP → Nouvelle adresse. Une adresse appartient toujours à un sous-réseau ; les champs nom d'hôte, adresse MAC et description sont optionnels.

Permissions requises : ROLE_ADMIN ou ROLE_IP.

Assistant IP disponible

Une fois un sous-réseau sélectionné dans le formulaire, le bouton Suggérer une IP disponible s'active. Cliquer sur une IP proposée remplit automatiquement le champ adresse — évite de calculer manuellement quelles adresses du bloc sont déjà prises.

Réservation multiple

Menu Adresses IP → ⊞ Réserver plusieurs IP. Cet outil génère jusqu'à 50 adresses disponibles d'un sous-réseau choisi, sous forme de tableau éditable : complétez les descriptions ou noms d'hôte ligne par ligne, puis réservez toutes les lignes en un seul clic. Pratique pour préparer un lot d'adresses avant un déploiement.

Permissions requises : ROLE_ADMIN ou ROLE_IP.

Rechercher une adresse

Menu Adresses IP. Filtres disponibles : recherche libre, nom d'hôte, adresse MAC. La liste est paginée (25 adresses par page).

Export

Boutons ↓ CSV et ↓ Excel disponibles sur les pages Adresses IP et Sous-réseaux. Les filtres actifs au moment de l'export sont appliqués au fichier généré.
