Mon compte & sécurité

Changer votre mot de passe et activer l'authentification à deux facteurs (MFA).

Changer son mot de passe

Menu Profil → Changer le mot de passe. Réservé aux comptes locaux — les comptes LDAP ont leur mot de passe géré par l'annuaire de l'entreprise, pas depuis Subnetory.

Politique de mot de passe : entre 12 et 128 caractères, avec au moins une majuscule, une minuscule, un chiffre et un caractère spécial.

Authentification à deux facteurs (MFA)

Chaque compte local peut activer un second facteur TOTP (compatible Google Authenticator, Authy, etc.) depuis son profil. Le MFA est optionnel : il n'est jamais imposé automatiquement. Les comptes LDAP ne sont pas concernés.

Activer le MFA

Menu Profil → Authentification à deux facteurs (MFA) → Activer le MFA.
Scanner le QR code affiché avec une application d'authentification, ou saisir la clé manuellement si le scan n'est pas possible.
Saisir le code à 6 chiffres généré par l'application pour confirmer.
Noter immédiatement les 10 codes de récupération affichés : ils ne seront plus jamais montrés ensuite. Les conserver dans un gestionnaire de mots de passe ou un coffre-fort, jamais en clair sur le poste de travail.

Se connecter avec le MFA actif

Après identifiant et mot de passe, une page dédiée demande le code TOTP (ou un code de récupération). Un code de récupération peut remplacer le code TOTP pour la connexion, la désactivation du MFA ou la régénération des codes — chaque code de récupération n'est utilisable qu'une seule fois.

Désactiver le MFA ou régénérer les codes

Depuis Profil, une fois le MFA actif : régénérer les 10 codes de récupération (invalide les anciens), ou désactiver le MFA. Les deux actions exigent un code MFA valide ; la désactivation exige en plus le mot de passe actuel.

Perte d'accès (appareil et codes de récupération perdus) : si un autre compte administrateur existe, il peut désactiver le MFA de votre compte depuis l'écran de détail utilisateur. Si aucun autre compte administrateur n'existe, contactez la personne en charge de l'exploitation du serveur — une procédure de secours existe mais nécessite un accès direct à la base de données.
